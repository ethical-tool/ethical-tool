ABOUT ME

I'm an ethical hacker and security researcher specializing in Web Application Security & Penetration Testing. My expertise spans red-team operations, vulnerability assessment and advanced security research — with a strong focus on open-source security tooling and CTFs.

What I focus on every day: Open-Source Security Tools, CTFs & Advanced Security Research. I build utilities that run on Kali Linux, document what I learn, and share it with the community — because security knowledge grows fastest when it's open.

Everything I do follows one rule: strict authorization. No unauthorized access, no malicious exploitation — only understanding attacks well enough to stop them.
